## 这是什么

《杀戮尖塔 2》的练习与救场模组 —— 把「重来」做到极致。

所有重启都基于**完整运行快照回滚**：不是"重新生成一个房间"，而是把整个游戏状态（血量 / 金币 / 牌组 / 遗物 / 药水 / 地图进度 / 随机数状态）精确还原到某个时间点，并经游戏官方的读档流程恢复 —— 与主菜单「继续游戏」走同一条路径，不做手工状态修补。

因此：重启后的牌序、怪物编成、商店库存、事件内容、宝箱遗物与首次完全一致，可以反复练习同一场战斗的不同打法。

## 四类重启

两个入口：暂停菜单里的四个重启按钮（按钮上实时显示当前幕数），以及快捷键（战斗中可直接按，无需打开菜单）。

| 操作 | 默认键 | 回滚到 | 确认框 | 说明 |
|---|---|---|---|---|
| **重启房间** | `R` | 点击本节点之前 | **免确认**，可连按 | 回滚后自动重新进入本房间 |
| **重启本层** | `F` | 本幕起点 | 有 | 落点为地图屏，可重新选路 |
| **重启本局** | `T` | —— | 有 | 同角色同种子从头重开（地图/房间与原来一致）|
| **重启新局** | `N` | —— | 有 | 同角色、新随机种子、全新开局 |

**重启房间**具体回退到什么：

- 手牌 / 抽牌堆 / 怪物编成 / 意图 与首次进房完全一致（RNG 一并回滚）
- 商店库存、事件内容、宝箱遗物同样不会刷新（反复重启都是同一批）
- 问号节点的房间内容也不会变（基于"掷骰之前"的快照重演同一次掷骰）
- 适合：反复练习同一场战斗 / 商店选错想重来
- 防误触由 0.5 秒冷却承担（连按不会叠发）

**重启本层**回退的是本幕获得的金币 / 卡牌 / 遗物 / 药水 / 血量，地图进度一并回退。进入每一幕时"幕初快照"会自动保存到磁盘，所以即使读档继续游戏、甚至大退重开游戏，按 `F` 也能回到**真正的幕初**。

## 刀下留人

生命归零时自动拦截死亡：先把玩家复活、冻结战斗，再弹出选择框。

- **「回到地图重新挑战」**：回滚到**进入本房间之前（选路前）**并停在地图界面 —— 血量 / 牌组 / 金币 / 药水全部回退，连地图上的访问记录一并回退（相当于"这一格还没走过"），可以重新选路，也可以重新进入刚才那个节点再战。
- **「放弃本局」**：同一种子从头重开。每日挑战局里这一项改为「按游戏正常流程结算本次失败」（见[已知限制](#每日挑战局只保留刀下留人)）。

两个开关与边界：

- 作用范围：**仅战斗中致死**。详见[已知限制](#刀下留人只在战斗中生效)。
- 配置项：`EnableDeathIntercept`（默认开启）。

## 快捷键

暂停菜单 → **快捷键设置** → 点击一行后按下新按键（`Esc` 取消），即时生效并写入配置文件。

默认键位：重启房间 `R` ｜ 重启本层 `F` ｜ 重启本局 `T` ｜ 重启新局 `N`

取值支持字母 / 数字 / 功能键，例如 `"R"`、`"Space"`、`"F1"`。

以下情况快捷键会被**主动忽略**（因为"重启房间"是免确认的不可逆操作，防误触优先），忽略原因会写进日志，便于定位"按了没反应"：

- 游戏窗口未获焦（Alt-Tab 出去后在别的程序里打字）
- 键盘焦点在文本输入框里
- 有模态弹窗打开着（包括本模组的"刀下留人"与确认框）
- 开发控制台（dev console）打开着

## 无痕保护

所有重启操作与刀下留人，都不会污染你的战绩：

- **不增加失败** —— 被重启的旧局面不会写入挑战历史
- **不断连胜** —— 连胜（win streak）不会因重启而中断
- **不记录成就** —— 旧局面静默消失，仿佛从未发生

实现方式：重启期间临时关闭游戏的存档写入开关（`RunManager.ShouldSave`），新局自动恢复 —— 与游戏正常"放弃本局并结算"的流程完全隔离。

> ⚠️ **一处如实说明**：回滚走的是游戏官方读档流程，而该流程自带"读档次数 +1 并写一次存档"（`SaveManager.IncrementNumReloads`，不受上面的存档开关约束）。所以战绩里的**读档次数**会把每次重启/回滚计入，结算时该计数也会随对局指标上传。历史 / 连胜 / 成就这三项不受影响。
>
> 如果哪天 `ShouldSave` 关不掉（游戏内部改动导致），屏幕上会直接提示"无痕保护未生效"，不会静默降级。

## 配置文件

路径：`%APPDATA%\SlayTheSpire2\mod_data\QuickRestart\settings.json`
首次运行自动生成；可直接编辑（重启游戏生效），快捷键也可在游戏内改。

| 字段 | 类型 | 说明 |
|---|---|---|
| `RestartRoomKey` | 字符串 | 重启房间快捷键（默认 `"R"`）|
| `RestartFloorKey` | 字符串 | 重启本层快捷键（默认 `"F"`）|
| `RestartRunKey` | 字符串 | 重启本局快捷键（默认 `"T"`）|
| `NewRunKey` | 字符串 | 重启新局快捷键（默认 `"N"`）|
| `EnableDeathIntercept` | 布尔 | 刀下留人开关（默认 `true`）|
| `ShowConfirmationDialog` | 布尔 | 确认弹窗开关（默认 `true`）。只影响重启本层/本局/新局与战后重新挑战；**重启房间始终免确认** |
| `FastRestartSkipMenu` | 布尔 | 重启时跳过主菜单中转（默认 `true`），显著缩短黑屏；若遇异常可改为 `false` 回退旧流程 |

老配置文件里若残留 `RetryCombatKey`、`EnableWinStreakProtection` 两个已删除的字段，会被自动忽略，不影响其它设置。

## 数据文件

配置目录 `%APPDATA%\SlayTheSpire2\mod_data\QuickRestart\` 下有两个文件：

| 文件 | 作用 |
|---|---|
| `settings.json` | 配置（见[配置文件](#配置文件)）|
| `act_start_snapshot.json` | 幕初快照，约 50KB |

关于幕初快照：

- 进入每一幕时自动把"本幕开场"的完整状态写入磁盘
- **只保留最新一份**：换幕自动覆盖、开新局自动清理、旧局残留自动删除
- 大小恒定约 50KB，不会越积越多，无需手动管理
- 它让"读档继续游戏 / 大退重开"之后按 `F` 依然能回到真正的幕初

## 工作原理

1. **快照回滚** —— 选路前 / 幕起点自动保存完整运行快照（含随机数状态）。重启 = 官方读档流程（`RunState.FromSerializable` → 读档建立 → 恢复场景），与「继续游戏」同一条路径。
2. **精确重现** —— 快照捕获于"点击地图节点之前"（问号房掷骰之前）→ 重新进入时重演同一次掷骰 / 抽取遭遇 / 洗牌，用的是同一份随机数 → 内容与首次一致。
3. **精确落点** —— 不使用官方"重进最后访问节点"的读档方式（那会往地图历史追加新格子、导致"前进一层"），而是明确落点：停在地图屏 / 按原坐标重进本节点。
4. **幕初持久化** —— 见[数据文件](#数据文件)。
5. **无痕** —— 重启期间临时关闭存档写入开关，新局自动恢复（见[无痕保护](#无痕保护)）。

## 已知限制

### 本幕开场数据不存在时，只能回到读档点

如果"本幕开始时 mod 尚未运行"（例如首次安装 mod 时你已经在幕中），磁盘上没有该幕的幕初数据 —— 此时按 `F` 只能回到「读档时」的状态，而不是本幕开场。

- 过场黑幕会明确提示："本幕快照来自读档点：只能回到「读档时」的状态"
- 从下一幕开始即恢复正常（进入新幕时自动记录幕初快照）
- 另一种会走到这里的情况：游戏更新导致 mod 取不到"局标识"时，为防把上一局的快照串进本局，会**主动拒绝**采用磁盘幕初数据

### 每日挑战局只保留刀下留人

- **不可用**：重启房间 / 重启本层 / 重启本局 / 重启新局 / 战后重新挑战（快捷键会提示"每日挑战局不支持"，菜单里也不再出现这些按钮）。原因：重开一局拿不到每日结算依据（`DailyTime` 不在对局状态里），"重启新局"更等于对同一份每日种子无限重 roll。
- **仍可用**：刀下留人。【确认】回到地图重新挑战 = 照常原地回滚（不改种子）；【取消】放弃本局 = 按游戏官方流程正常结算本次失败（不是普通局的"无痕同种子重开"，弹窗文案会写明）。

### 联机对局完全不生效

联机对局由输入同步与校验和保护，本地单方面回滚会被判定为状态不一致，无法安全工作。因此联机下：快捷键不响应（有文字提示）、菜单里不显示按钮、生命归零不拦截。单人模式完全不受影响。

### 刀下留人只在战斗中生效

拦截点是战斗管理器里的"逐玩家死亡处理"与"战斗失败标记"两处，所以事件房扣血、诅咒、药水反噬等**战斗外**把血量打到 0 不会被救 —— 这类死亡按游戏官方流程正常结算，这是设计边界，不是漏拦截。

### 弹窗选择期间战斗是冻结的

作出选择、或弹窗被任何方式关掉（`Esc` 等）时都会自动解除暂停。

### 降级路径只回血量

若"点击节点前"的快照不可用（例如本房间不是从地图节点进入的），"重启房间"会退化为"新建同名房间重进"：只回退血量，金币/卡牌不回退、牌序重新随机。正常游玩（从地图点节点进房）不会走到这里。

### 重启耗时分两档

- 回滚类（重启房间 / 重启本层 / 刀下留人回到地图）：约 **0.65 ~ 0.70 秒**
- 重开整局（重启本局 / 重启新局）：约 **2.5 秒**，大头是游戏的角色与幕资源预载 + 地图生成，不是黑幕动画

若出现一直黑屏 / 画面错乱等异常，把 `FastRestartSkipMenu` 改为 `false`（回退旧流程）并到 [Issues](https://github.com/fengzhenhong/QuickRestart/issues) 反馈。

## 常见问题

**Q：重启房间后商店 / 事件内容会变化吗？**
A：不会。反复重启都是同一批（牌序、怪物、商店库存、事件、宝箱一致）。

**Q：重启会记为失败吗？会断连胜吗？**
A：不会 —— 不写历史、不记失败、不断连胜、不记成就。只有"读档次数"会计入，见[无痕保护](#无痕保护)。

**Q：战斗中死亡了还能救吗？**
A：能。生命归零时弹出「刀下留人」，选「回到地图重新挑战」即可回退到进入本房间之前，可重新选路或重进本节点再战。

**Q：读档继续游戏后按 `F`，为什么有时只回到读档位置？**
A：见[本幕开场数据不存在时](#本幕开场数据不存在时只能回到读档点)。黑幕会有明确提示，进入下一幕 / 重开一局后恢复正常。

**Q：需要为「重启本层」手动存档吗？**
A：不需要，全自动。

**Q：每日挑战局能用吗？**
A：一半能用。四类"重启"与战后"重新挑战"被禁用（因为它们要重开一局、拿不到每日结算依据）；但"刀下留人"照常生效 —— 【确认】回到地图原地重打这一格可以给，【取消】按游戏正常流程结算这次失败。

**Q：为什么有时按快捷键没反应？**
A：窗口未获焦、焦点在文本框、已有弹窗打开、控制台打开这四种情况会被主动忽略（重启房间是免确认的不可逆操作，防误触优先）。

**Q：多人联机能用吗？**
A：不能，见[联机对局完全不生效](#联机对局完全不生效)。
