回溯之镜（QuickRestart）· 完整功能说明
============================================================

版本：0.1.6  ·  更新日期：2026-09-19
适用游戏：杀戮尖塔 2（Slay the Spire 2）v0.111 或更高
前置依赖：STS2-RitsuLib ≥ 0.5.18（兼容 0.6.x）
项目主页：https://github.com/fengzhenhong/QuickRestart


------------------------------------------------------------
一、这是什么
------------------------------------------------------------
《杀戮尖塔 2》的练习与救场模组 —— 把「重来」做到极致。

所有重启都基于【完整运行快照回滚】：不是"重新生成一个房间"，而是把整个
游戏状态（血量 / 金币 / 牌组 / 遗物 / 药水 / 地图进度 / 随机数状态）精确
还原到某个时间点，并经游戏官方的读档流程恢复 —— 与主菜单「继续游戏」走
同一条路径，不做手工状态修补。

因此：重启后的牌序、怪物编成、商店库存、事件内容、宝箱遗物与首次完全
一致，可以反复练习同一场战斗的不同打法。


------------------------------------------------------------
二、四类重启
------------------------------------------------------------
入口一：暂停菜单 → 四个重启按钮（按钮上实时显示当前幕数）
入口二：快捷键（默认见下，可在游戏内自定义）

【重启房间】      快捷键 R     免确认，可直接连按
  回滚到「点击本节点之前」并自动重新进入本房间。
  - 手牌 / 抽牌堆 / 怪物编成 / 意图 与首次进房完全一致（RNG 一并回滚）
  - 商店库存、事件内容、宝箱遗物同样不会刷新（反复重启都是同一批）
  - 问号节点的房间内容也不会变（基于"掷骰之前"的快照重演同一次掷骰）
  - 适合：反复练习同一场战斗 / 商店选错想重来
  - 防误触由 0.5 秒冷却承担（连按不会叠发）

【重启本层】      快捷键 F
  回滚到「本幕起点」：
  - 本幕获得的金币 / 卡牌 / 遗物 / 药水 / 血量 全部回退
  - 地图进度一并回退，落点为地图屏（本幕起点）
  - v0.1.4 起：进入每一幕时自动保存"幕初快照"到磁盘 ——
    即使你读档继续游戏、甚至大退重开游戏，按 F 也能回到【真正的幕初】
  - 保留确认框（大幅回退操作，防误触）

【重启本局】      快捷键 T
  同一随机种子从头开始（地图 / 房间与原来一局一致）：
  - 无痕保护：旧局面不会写入历史、不会中断连胜、不记成就
  - 保留确认框

【重启新局】      快捷键 N
  同角色、新随机种子、全新开局。保留确认框。


------------------------------------------------------------
三、刀下留人
------------------------------------------------------------
生命归零时自动拦截死亡，弹出「刀下留人」弹窗（战斗冻结）：

  - 「回到地图重新挑战」：
      回滚到【进入本房间之前（选路前）】并停在地图界面 ——
      血量 / 牌组 / 金币 / 药水全部回退，连地图上的访问记录一并回退
      （相当于"这一格还没走过"），可以重新选路，也可以重新进入刚才
      那个节点再战。
  - 「放弃本局」：
      同一种子从头重开。
      ※ 每日挑战局里这一项改为「按游戏正常流程结算本次失败」
        （每日局不能无痕重开，见第九节第 6 条）

作用范围：仅【战斗中】致死（详见第九节第 9 条）。
开关：配置项 EnableDeathIntercept（默认开启）。
说明：拦截依赖游戏的两个死亡入口（HandlePlayerDeath 与失败标记），
      拦截后会先把玩家复活再冻结战斗，等待你的选择。


------------------------------------------------------------
四、快捷键（游戏内可自定义）
------------------------------------------------------------
暂停菜单 → 快捷键设置 → 点击一行后按下新按键（Esc 取消），
即时生效并写入配置文件。

默认键位：
  重启房间 = R      重启本层 = F      重启本局 = T      重启新局 = N

   快捷键在战斗中也能直接按，无需打开菜单。
   打开控制台（dev console）时快捷键不响应，不会干扰你在控制台里的输入。


------------------------------------------------------------
五、无痕保护（重要）
------------------------------------------------------------
所有重启操作与刀下留人，都不会污染你的战绩：

  - 不增加失败：被重启的旧局面不会写入挑战历史
  - 不断连胜：连胜（win streak）不会因重启而中断
  - 不记录成就：旧局面静默消失，仿佛从未发生

实现方式：重启期间临时关闭游戏的存档写入开关，新局自动恢复 ——
与游戏正常的"放弃本局并结算"流程完全隔离。

⚠️ 一处如实说明：回滚走的是游戏【官方读档流程】，而该流程自带
   "读档次数 +1 并写一次存档"（SaveManager.IncrementNumReloads，
   不受上面的存档开关约束）。所以战绩里的【读档次数】会把每次
   重启/回滚计入，结算时该计数也会随对局指标上传。
   历史 / 连胜 / 成就这三项不受影响。


------------------------------------------------------------
六、配置文件
------------------------------------------------------------
路径：%APPDATA%\SlayTheSpire2\mod_data\QuickRestart\settings.json
说明：首次运行自动生成；可直接编辑（重启游戏生效），快捷键也可在游戏内改。

字段一览：
  RestartRoomKey           字符串  重启房间快捷键（默认 "R"）
  RestartFloorKey          字符串  重启本层快捷键（默认 "F"）
  RestartRunKey            字符串  重启本局快捷键（默认 "T"）
  NewRunKey                字符串  重启新局快捷键（默认 "N"）
  EnableDeathIntercept     真假    刀下留人开关（默认 true）
  ShowConfirmationDialog   真假    确认弹窗开关（默认 true）
                                   ※ 只影响 重启本层/本局/新局；
                                     重启房间始终免确认
  FastRestartSkipMenu      真假    重启时跳过主菜单中转（默认 true）
                                   ※ 显著缩短黑屏；若遇异常可改为 false 回退旧流程

按键取值示例："R"  "Space"  "F1"  （字母 / 数字 / 功能键均可）

※ v0.1.6 起删除两个从未生效的字段：
    RetryCombatKey            从未接上任何按键读取点，改了不会有效果
    EnableWinStreakProtection 预留字段，无实现
  老配置文件里残留这两个键会被自动忽略，不影响其它设置。


------------------------------------------------------------
七、数据文件说明
------------------------------------------------------------
配置目录：%APPDATA%\SlayTheSpire2\mod_data\QuickRestart\

  settings.json             配置文件（见第六节）
  act_start_snapshot.json   幕初快照（约 50KB）

关于幕初快照（v0.1.4 新增）：
  - 进入每一幕时自动把"本幕开场"的完整状态写入磁盘
  - 只保留最新一份：换幕自动覆盖、开新局自动清理、旧局残留自动删除
  - 大小恒定约 50KB，不会越积越多，无需手动管理
  - 它让"读档继续游戏 / 大退重开"之后按 F 依然能回到真正的幕初


------------------------------------------------------------
八、工作原理（简述）
------------------------------------------------------------
1. 快照回滚
   进房前 / 幕起点 / 开局 自动保存完整运行快照（含随机数状态）。
   重启 = 官方读档流程（RunState.FromSerializable → 读档建立 →
   恢复场景），与「继续游戏」同一条路径。

2. 精确重现
   快照捕获于"点击地图节点之前"（问号房掷骰之前）→ 重新进入时重演
   同一次掷骰 / 抽取遭遇 / 洗牌，用的是同一份随机数 → 内容与首次一致。

3. 精确落点
   不使用官方"重进最后访问节点"的读档方式（那会往地图历史追加新格子、
   导致"前进一层"），而是明确落点：停在地图屏 / 按原坐标重进本节点。

4. 幕初持久化
   见第七节。

5. 无痕
   重启期间临时关闭存档写入开关，新局自动恢复（见第五节）。


------------------------------------------------------------
九、已知限制 / 注意事项
------------------------------------------------------------
1. 「读档点」限制（本幕开场数据不存在时）
   如果"本幕开始时 mod 尚未运行"（例如首次安装 mod 时你已经在幕中），
   磁盘上没有该幕的幕初数据 —— 此时按 F 只能回到「读档时」的状态，
   而不是本幕开场。
   · 过场黑幕会明确提示："本幕快照来自读档点：只能回到「读档时」的状态"
   · 从下一幕开始即恢复正常（进入新幕时自动记录幕初快照）
   · 另一种会走到这里的情况：游戏更新导致 mod 取不到"局标识"时，
     为防把上一局的快照串进本局，会主动拒绝采用磁盘幕初数据（v0.1.6 起）

2. 重启房间为免确认设计；重启本层 / 本局 / 新局保留确认框。

3. 刀下留人弹窗选择期间战斗处于冻结状态；作出选择、或弹窗被任何
   方式关掉（Esc 等）时都会自动解除暂停（v0.1.6 起补全）。

4. 「重启本局」= 同种子从头（内容与原来一致）；
   「重启新局」= 新种子全新开局。两者都会重置幕初快照（新局会重新记录）。

5. 重启耗时分两档（v0.1.6 实测，同一份游戏日志）
   - 回滚类（重启房间 / 重启本层 / 刀下留人回到地图）：约 0.65 ~ 0.70 秒
   - 重开整局（重启本局 / 重启新局）：约 2.5 秒
     大头是游戏的角色与幕资源预载 + 地图生成，不是黑幕动画。
   若出现一直黑屏 / 画面错乱等异常，把 FastRestartSkipMenu 改为 false
   （回退旧流程）并到 GitHub Issues 反馈。

6. 每日挑战局：禁"重启"，保留"刀下留人"（v0.1.6 起）
   - 不可用：重启房间 / 重启本层 / 重启本局 / 重启新局 / 战后重新挑战
     （快捷键会提示"每日挑战局不支持"，菜单里也不再出现这些按钮）。
     原因：重开一局拿不到每日结算依据（DailyTime 不在对局状态里），
     "重启新局"更等于对同一份每日种子无限重 roll。
   - 仍可用：刀下留人。【确认】回到地图重新挑战 = 照常原地回滚（不改种子）；
     【取消】放弃本局 = 按游戏官方流程正常结算本次失败
     （不是普通局的"无痕同种子重开"，弹窗文案会写明）。

7. 以下情况快捷键不触发（防误触造成不可逆回滚，v0.1.6 起）
   - 游戏窗口未获焦（Alt-Tab 出去后在别的程序里打字）
   - 键盘焦点在文本输入框里
   - 有模态弹窗打开着（包括本模组的"刀下留人"与确认框）
   - 开发控制台打开着
   原因会写进日志，方便"按了没反应"时定位。

8. 降级路径只回血量
   若"点击节点前"的快照不可用（例如本房间不是从地图节点进入的），
   "重启房间"会退化为"新建同名房间重进"：只回退血量，金币/卡牌不回退、
   牌序重新随机。正常游玩（从地图点节点进房）不会走到这里。


9. 刀下留人只在【战斗中】生效
   拦截点是战斗管理器里的"逐玩家死亡处理"与"战斗失败标记"两处，
   所以：事件房扣血、诅咒、药水反噬等【战斗外】把血量打到 0 不会被救，
   这类死亡按游戏官方流程正常结算 —— 这是设计边界，不是漏拦截。

------------------------------------------------------------
十、常见问题
------------------------------------------------------------
Q：重启房间后商店 / 事件内容会变化吗？
A：不会。反复重启都是同一批（牌序、怪物、商店库存、事件、宝箱一致）。

Q：重启会记为失败吗？会断连胜吗？
A：不会。无痕保护：不写历史、不记失败、不断连胜、不记成就。

Q：战斗中死亡了还能救吗？
A：能。生命归零时弹出「刀下留人」，选「回到地图重新挑战」即可回退到
   进入本房间之前，可重新选路或重进本节点再战。

Q：读档继续游戏后按 F，为什么有时只回到读档位置（提示"读档点"）？
A：见第九节第 1 条：本幕开始时 mod 不在运行的历史存档没有幕初数据，
   黑幕会有明确提示。进入下一幕 / 重开一局后即恢复正常。

Q：需要为「重启本层」手动存档吗？
A：不需要，全自动。

Q：每日挑战局能用吗？
A：一半能用（v0.1.6 起）。四类"重启"与战后"重新挑战"被禁用（会提示），
   因为它们要重开一局、拿不到每日结算依据；但"刀下留人"照常生效 ——
   【确认】回到地图原地重打这一格可以给，【取消】则按游戏正常流程
   结算这次失败（不会无痕重开）。

Q：为什么有时按快捷键没反应？
A：以下情况会被主动忽略：窗口未获焦、焦点在文本框、已有弹窗打开、
   控制台打开。这是为了防误触（重启房间是免确认的不可逆操作）。

Q：多人联机能用吗？
A：不能 —— 联机对局中本模组会【完全静默】：快捷键不响应（有文字提示）、
   菜单里不显示按钮、生命归零不拦截。原因是联机对局由输入同步与校验和
   保护，本地单方面回滚会被判定为状态不一致，无法安全工作。
   单人模式完全不受影响。

十二、安装（三步）与反馈
------------------------------------------------------------
1. 安装前置库 STS2-RitsuLib（≥ 0.5.18）：
   https://github.com/BAKAOLC/STS2-RitsuLib
   （0.6.0 请安装官方完整包：含 shared\、compat\、assets.zip，不能只复制根 DLL）

2. 把 QuickRestart 文件夹整个解压到游戏目录的 mods\ 下：
   ...\Slay the Spire 2\mods\QuickRestart\QuickRestart.dll
                                  \QuickRestart.json

3. 启动游戏。暂停菜单里出现四个重启按钮即安装成功。

反馈 / 建议：https://github.com/fengzhenhong/QuickRestart/issues
